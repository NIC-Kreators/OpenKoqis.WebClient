Кто такой Root Admin

Это главный аккаунт системы. Прежде чем создавать его, важно понять, чем он отличается от обычного.

  • Полный доступ Root Admin может всё: видеть и менять любые данные и настройки.
  • Управляет администраторами Создаёт других администраторов и раздаёт им права.
  • Его важно защитить Если этот аккаунт взломают, под угрозой окажется вся система. Используйте надёжный пароль и никому его не передавайте.
  • Не для каждого дня Для обычной работы создайте отдельный аккаунт администратора, а Root Admin держите на крайний случай.
